# Kaivalya Vijay Kubade — Data Analytics Portfolio 📊🚀

A modern, responsive, high-performance portfolio website showcasing projects, interactive dashboards, machine learning applications, technical skills, and achievements in Data Analytics & Business Intelligence.

---

## 🌟 Highlights & Features

- **Interactive Analytics Sandbox**: Real-time KPI forecasting simulator and dynamic live chart previews powered by Chart.js.
- **Project Showcase**: End-to-end data analytics, machine learning, and BI case studies with full detail modals, KPI tags, and tech stack badges:
  - *Autonomous Car Rental System* (Python, MySQL, PyQt5, Analytics)
  - *Sales Performance & Revenue Analytics Dashboard* (Power BI, DAX, Power Query)
  - *Customer Churn Prediction Engine* (Python, Scikit-learn, Seaborn, Matplotlib)
  - *Global Healthcare & COVID-19 Analytics* (Tableau, Excel, Public Health Data)
- **Interactive Experience & Education Timeline**: Detailed career progression, academics, and practical analytics milestones.
- **Skill Proficiency Matrix**: Technical proficiencies categorized across Python/SQL, Data Visualization, ML/Statistics, and Analytics Tools.
- **Modern UI / UX**:
  - Dark / Light mode toggle with persistent local storage
  - Glassmorphism, cyber neon accents, responsive mobile navigation
  - Back-to-top button, smooth scroll anchors, and interactive contact form with copy-to-clipboard actions.

---

## 🛠️ Built With

- **HTML5** (Semantic structure & SEO metadata)
- **CSS3** (Custom design system, CSS variables, glassmorphism, responsive grid & flexbox)
- **JavaScript (ES6+)** (Dynamic charting, interactive filtering, project modals, theme switcher)
- **Chart.js 4.4+** (Dynamic data visualizations and interactive metrics)
- **Font Awesome 6** & **Google Fonts** (Syne, Plus Jakarta Sans, JetBrains Mono)

## 🚀 Live Demo & Getting Started

1. Clone or download the repository:
   ```bash
   git clone https://github.com/keadr7/my_Portfolio.git
   ```
2. Open `index.html` in your favorite modern web browser or serve it locally:
   ```bash
   # Using Python 3 HTTP server
   python -m http.server 5173
   ```
3. Visit `http://localhost:5173` in your browser.
